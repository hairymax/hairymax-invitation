# Особенное приглашение

Небольшое приглашение на 31 октября в Москву, Сколково: личное приветствие для Ани, две фотографии, игривые кнопки и два финала. Обычные HTML, CSS и JavaScript, без сборки, библиотек и сервера.

## Посмотреть

Открыть `index.html` в браузере. Интернет не нужен: шрифты системные, картинки лежат в `assets/`.

## Поменять фотографии и дату

В начале `app.js` находится объект `INVITATION`:

- `originalPhoto` — путь к смешной оригинальной фотографии. Её выбор ведёт дальше.
- `polishedPhoto` — путь к улучшенной фотографии. Её выбор показывает шутку и позволяет попробовать снова.
- `togetherPhoto` — общая фотография фоном на финальном квитке; подготовлена из `assets/IMG_9522.tiff` и подключается из `assets/invitation-together.js`.
- `recipient` — обращение в приглашении. Сейчас «любимой Ане».
- `date` — дата в финальном приглашении. Сейчас «31 октября · ДР».
- `location` — место встречи. Сейчас «Москва, Сколково».
- `note` — текст внутри квитка. Сейчас «Ты сделаешь именинника счастливее».
- `playfulMoves` — количество перебежек кнопок. Сейчас четыре.

Новые фотографии положить в `assets/`, указать их пути и обновить описания `alt` у изображений в `index.html`.

Общая фотография уменьшена до 1800 пикселей по длинной стороне, сохранена как JPEG и встроена в `assets/invitation-together.js`: страница и скачиваемый квиток используют одну картинку. Подготовленный JS-файл весит около 570 КБ. Это обычный JPEG, записанный строкой внутри JS; такая упаковка позволяет сохранять PNG даже при открытии `index.html` с диска. Масштабирование, кадрирование и прозрачность задаются в `style.css` и при рисовании PNG в `app.js`.

Исходный TIFF остаётся на компьютере и исключён из Git через `.gitignore`. Для работы сайта и публикации он не нужен: в коммит достаточно включить `assets/invitation-together.js`. При замене TIFF подготовленную копию нужно обновить отдельно — сайт сам исходник не перечитывает. Две фотографии для первого вопроса по-прежнему подключаются как обычные JPG и PNG.

## Поведение кнопок

На компьютере обе кнопки перемещаются при приближении курсора. На телефоне — при касании. Касание, запустившее движение, не подтверждает ответ. После четырёх перемещений, паузы или нажатия «Ладно, без фокусов» доступны оба ответа. Управление клавиатурой и настройка уменьшения движения отключают игру.

После выбора фото наведение включается через 750 мс и требует нового движения курсора: кнопка, появившаяся под мышью, не убегает сама. Отдельное нажатие на кнопку сразу запускает шутку. Реплики появляются только после взаимодействия.

Ответ меняет только страницу в браузере: сообщения никуда автоматически не отправляются.

## Сохранить приглашение

В финале согласия кнопка «Скачать приглашение» сохраняет отдельную PNG-картинку 1800 × 1000: квиток с общей фотографией, обращением, датой и местом. Текст берётся из того же объекта `INVITATION`, что и на странице. Картинку можно переслать, сохранить или распечатать. Она создаётся прямо в браузере, без доступа к сети и сторонних сервисов. Подпись «Буду ждать тебя» и кнопки остаются только на странице.

## Публикация

GitHub Pages может отдавать эти файлы прямо из корня ветки `main`. Если эта ветка уже выбрана в Pages, отправка изменений в неё обновит публичный сайт. Перед отправкой проверить содержимое и фотографии.
